Scenario data card · demo

A predetermined card that fills as you go

Every detail the tools can carry has its own reserved cell, laid out up front. A cell sits in an awaiting state until you confirm it — set that input or finish that tool — then it fills in. The grid never reflows, there are no empty trailing gaps, and you can see at a glance what's done and what's left.

Option A — predetermined field grid
Try it — confirm a detail (stands in for using a tool)

How it maps to the real tools: the cells are the full set of things the scenario can hold — carried inputs (pay bill, age, status) plus each tool's headline output (claimable per hire, NI saving, best-fit standard, funding status, at-risk, health). A cell flips to confirmed the instant you provide that input or complete that tool, carried automatically across every tool. Tap any cell above to toggle it, or use the buttons.
